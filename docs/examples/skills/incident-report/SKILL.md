# Incident report

## Procedure

1. Write an incident summary and impact scope.
2. Build a timeline from observed timestamps and actions.
3. Link evidence to the root-cause assessment.
4. Record completed and failed actions with their outcomes.
5. List follow-up actions and remaining uncertainty.

## Constraints

Use only supplied or retrieved facts. Preserve original timestamps, service names, and identifiers. Mark an unconfirmed cause as unverified.
