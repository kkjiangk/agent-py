# Knowledge search

## Procedure

1. Retrieve knowledge when the question needs project-specific evidence.
2. Include the service, symptom, and operational goal in search terms.
3. Prefer relevant passages with identifiable sources.
4. Keep recommendations consistent with retrieved content.
5. If nothing matches, report that result and clearly label any general guidance.

## Constraints

Use only knowledge the current user may access. Provide findings, suggested steps, caveats, and source citations; never invent a hit.
